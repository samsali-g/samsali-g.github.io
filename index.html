Browser-First Static Web Utilities

Fast, client-side, privacy-respecting static web tools built and deployed on Cloudflare Pages.

ExifStudio — Browser EXIF & Photo Metadata Editor

Inspect, edit, and strip EXIF, GPS location tags, and camera metadata directly in your browser without uploading photos to any remote server. Supports JPEG, PNG, HEIC, WebP, and PDF Info cleaning in local memory.

  • Shutter Count Checker
  • EXIF Metadata Inspector
  • GPS Geotag Scrubber
  • PDF Metadata Cleaner
  • Print DPI Converter
  • HEIC to JPG Tool
  • About ExifStudio

Alfalaki — Interactive Astronomy & Lunar Ephemeris

Client-side VSOP87 & ELP2000 astronomical toolkit featuring interactive natal charts, trilingual daily transit scopes, 3D star maps, eclipse schedules, and topocentric Hilal crescent visibility predictions.
