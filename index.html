Browser-First Static Web Utilities

Fast, client-side, privacy-respecting static web tools built and deployed on Cloudflare Pages.

ExifStudio — Browser EXIF & Photo Metadata Editor

Inspect, edit, and strip EXIF, GPS location tags, and camera metadata directly in your browser without uploading photos to any remote server. Supports JPEG, PNG, and WebP formats with batch processing.

Alfalaki — Interactive Astronomy & Lunar Ephemeris

Client-side astronomical computation toolkit featuring live 3D sky maps, solar and lunar eclipse timelines, planetary coordinates, moon phases, and Islamic Hijri lunar visibility calculations.

WedMaroc — Moroccan Wedding Planner & Vendor Directory

Interactive Moroccan wedding planning workspace with city-by-city venue and vendor directories, budget estimation tools, timelines, and printable checklists tailored for ceremonies across Morocco.
